Glosario de Términos

Conceptos clave sobre inteligencia artificial, agentes y desarrollo

Agente

Entidad que actúa de forma autónoma para lograr un objetivo.

Multiagente

Conjunto de agentes autónomos que colaboran para lograr un objetivo.

Utilidad de un Multiagente

Sirve para resolver problemas complejos mediante la colaboración de múltiples agentes.

Droid

Robot con inteligencia artificial que realiza tareas de forma autónoma.

Fake Bot

Programa automatizado que simula ser un usuario humano o legítimo.

Repositorio

Sirve para almacenar, gestionar versiones de código y colaborar en equipo.

GitHub

Plataforma para alojar, gestionar y compartir código fuente.

Funcionamiento de GitHub

Rastrea versiones de código online facilitando el trabajo en equipo.

Diferencia entre Claude y Droid

Claude es un software conversacional y Droid un robot físico.

Open Claude

Versión de código abierto de Claude compatible con múltiples modelos.

Open Cloud

Nube construida con código abierto para garantizar flexibilidad e interoperabilidad.

Sección de uso en Ollama

Sección que muestra las métricas de rendimiento y tokens consumidos.

Sistema predictivo de agentes

Sistema de agentes autónomos que anticipan eventos futuros para decidir.

Capacitaciones con un agente

Permite simular escenarios reales para entrenar personal de forma eficiente.

Unskills

Término que describe la falta de habilidades o capacitación técnica.
